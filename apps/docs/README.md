# Merran public site

Astro + Starlight, built independently from the household app. Run `pnpm docs:dev` from the repository root, or `pnpm docs:build` for the static output in `apps/docs/dist`.

- `src/pages/index.astro`: homepage; HTML sections in `src/components/landing`, with separate CSS and browser interactions imported from the supplied export.
- `src/content/docs/docs`: public documentation at `/docs/`.
- API reference: generated by starlight-openapi from the server's committed OpenAPI document. `/openapi.json` exposes the same file.
- Fonts are bundled locally; the homepage does not require Google Fonts.
- `SITE_URL` configures the canonical origin; `SITE_BASE` supports GitHub project Pages paths.
- `scripts/check-links.mjs` validates internal page, asset, and fragment links after building.

The GitHub Pages workflow validates pull requests, uploads a reviewable artifact, and deploys only when manually dispatched with deployment enabled. Set the repository Pages source to GitHub Actions before deploying. For the planned domain, configure DNS and the Pages custom domain separately. No deployment happens just by pushing this branch.

See the repository's `docs/site-plan.md` for the remaining content inventory. Documentation text is intended for CC BY 4.0; application and site code remain AGPL-3.0-or-later.
