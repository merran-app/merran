Bring the weekly routine together

Keep recipes, plans and shopping connected, with optional AI when you want a hand.

  • Work with your own recipe library.The optional assistant can read household records and propose kitchen changes for you to approve.
  • Keep track of what is already home.Record amounts, use-by dates and food reserved for a planned meal. Comparable quantities can be deducted.
  • Review products before sending a list.Connect an eligible Kroger-family account to add products to its cart. Checkout stays with the retailer.
  • Make use of available nutrition data.Keep imported nutrition, calculate with a USDA key, or use optional AI estimates. Coverage varies by ingredient.

How it fits together

One loop, every week. AI when you want it.

Choose meals, add their ingredients to the list, and account for pantry stock. Put purchases away, then mark planned meals cooked to deduct their recorded stock. Optional AI can help along the way.

      Open source

      Do I need an AI key?

      AI features need an eligible provider key or compatible endpoint. Core recipes, planning, lists and pantry tracking work without AI; media features can have additional provider requirements. See the feature requirements →

      What does it run on?

      The container build targets Linux AMD64 and ARM64. Verify the image and requirements for your chosen release. Memory needs depend on workload and optional services; no measured minimum is published here.

      Is there a phone app?

      Merran is a web app. Supported browsers can install it on the home screen over HTTPS. Android sharing depends on browser support; iPhone sharing requires a Shortcut you configure in Settings. This does not promise offline operation.

      Can my whole family use it?

      Yes. Invite each person with a link and they make their own account. One server can host several households too, each kept separate. Households can use their own AI credentials when policy permits, or eligible shared server keys. Recorded-usage limits are not hard billing caps. Roles and permissions →

      Which stores can it send the list to?

      Eligible Kroger-family stores use a configured developer app and linked household account. Other stores, including Costco, use search links. Walmart cart filling is an opt-in extension experiment. Availability varies; checkout happens at the retailer.

      How do I move from Mealie?

      Open Settings → Import and export → From another app. Household admins can import a backup or recipe export; a server admin who also administers the destination household can connect with Mealie's address and an API token. Re-import skips known recipes rather than syncing edits. Follow the migration guide →

      Can I reach it away from home?

      Configure a tunnel, VPN or HTTPS reverse proxy, then set the public URL and trusted proxies for your deployment. Household data requires authorization, but setup, sign-in and some public endpoints are accessible before login. Follow the configuration guide before exposing the server.
